# mm

Сайт-визитка Михаила Макарова. Чистый HTML/CSS, без сборщиков, без фреймворков — открывается мгновенно и легко размещается на GitHub Pages бесплатно.

## Структура

```
index.html          Главная
about.html           Обо мне
articles.html        Все статьи
contacts.html        Контакты

articles/
  reputation.html     Как противостоять негативным вбросам
  account.html         Оформляем аккаунт чиновника правильно
  subscribers.html     Как привлекать подписчиков госструктуре
  press-conference.html Организуем пресс-конференцию

css/
  style.css           Общие стили сайта
  article.css         Типографика статей

js/
  script.js           Мобильное меню

img/
  portrait.jpg         Фото на главной
  og-image.jpg         Картинка для соцсетей (Open Graph)

favicon.svg
robots.txt
sitemap.xml
```

## Как опубликовать на GitHub Pages (бесплатно)

1. Создайте новый репозиторий на GitHub с названием `mm`.
2. Загрузите в него все файлы из этой папки, сохранив структуру (папки `articles/`, `css/`, `js/`, `img/` — как есть).
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Source** выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://makarovmedia.github.io/mm/`

## Готово к публикации

- Логин на GitHub — `makarovmedia`, репозиторий называется `mm`. Все ссылки (`robots.txt`, `sitemap.xml`, мета-теги `og:url`/`canonical`) уже настроены на адрес `https://makarovmedia.github.io/mm/` — менять ничего не нужно.
- Если в будущем переименуете репозиторий ещё раз или перенесёте сайт на свой домен, эти ссылки нужно будет обновить во всех файлах тем же способом («Найти и заменить»).
- Контакты (email и Telegram) уже заполнены настоящими данными в `contacts.html`.

## Добавление новой статьи

1. Скопируйте любой файл из `articles/` как шаблон.
2. Замените заголовок, мета-теги и текст.
3. Добавьте карточку-анонс на `articles.html` и (по желанию) в блок «Последние статьи» на `index.html`.
4. Добавьте новый адрес в `sitemap.xml`.

## Локальный просмотр

Файлы можно открыть прямо в браузере (двойной клик по `index.html`), сервер не требуется.
